# El Pollo Loco

A browser-based jump and run game built with HTML, CSS and JavaScript.

## Features

- Start screen with game instructions
- Keyboard controls
- Mobile touch controls
- Landscape-only mobile layout
- Collectable coins and bottles
- Throwable bottles
- Normal chickens, small chickens and endboss
- Health, coin, bottle and endboss status bars
- Game over and win screens
- Restart and home buttons
- Fullscreen mode
- Game sound effects with mute and volume control
- Background music with separate volume control
- Saved sound settings with LocalStorage
- Impressum overlay

## Controls

- Move left: Arrow Left
- Move right: Arrow Right
- Jump: Space
- Throw bottle: D

## Mobile Controls

On mobile and tablet devices, touch buttons are shown in landscape mode.  
In portrait mode, a rotate-screen message is displayed.
